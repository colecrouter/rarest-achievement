# Training Data

This directory contains persisted training data used to produce `packages/lib/steam_model.json`.

## Files

- `steam_data.csv` is the production training dataset generated by `build_bucketed_data.py`.
- `steam_data.metadata.json` records the source APIs and generation parameters for `steam_data.csv`.

## Workflow

Use `python/xgboost_model/output` for throwaway comparisons and smoke-test output. That directory is git-ignored.

Use `python/xgboost_model/input` for reviewed datasets that should be committed and used to reproduce a model. Do not commit raw API dumps unless they are intentionally part of the training corpus.

Generate the production dataset with:

```powershell
python/xgboost_model/venv/Scripts/python.exe python/xgboost_model/build_bucketed_data.py
```
